# VoiceBox — Professional Voice Assistant for Windows

White, smooth, calm — runs quietly in background.

- **Left Ctrl + Left Alt** → Ask anything by voice (top card + spoken)
- **Left Ctrl + Left Shift** → Analyze your screen (capture + ask "what does this say?")
- Nicer neural voices (Edge TTS: Aria/Jenny/Guy), 9 languages
- Free AI forever: Groq Llama 3.1 (free key) / Ollama offline / Wikipedia+offline writer that writes essays
- Gmail optional via OAuth

## Quick Start
```bash
cd app
pip install -r requirements.txt
python main.py
# Follow the 8-step tour: Welcome → Language → Voice → Hotkeys → Permissions → AI → Gmail → Ready
```
