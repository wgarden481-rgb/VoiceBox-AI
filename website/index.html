How it works — just download, answer, use

No demos on the website, no extra files to open. The app itself shows you everything step-by-step after download.

⬇

1 — One download, one double-click

VoiceBox-Setup.exe (79MB). Double-click → UAC Yes → white “Installing…” window with progress. It extracts to %LOCALAPPDATA%\VoiceBox, installs libraries offline from wheels/, creates Start Menu shortcut, adds startup, launches. No ZIP to unzip, no second file to open.

◎

2 — Answer the 8-step tour

The app walks you through: Welcome → Language → Voice (test) → Hotkeys → Permissions (Allow mic/screen) → AI free → Gmail (optional) → Ready. Each step has Next/Back — answer what matters, then you’re done.

▣

3 — Press and use — that’s it

Left Ctrl+Alt = Ask anything. Left Ctrl+Shift = Analyze screen (“what does this say?”). Top card + spoken answer. No other windows needed.

⚠️ First download may show “Not commonly downloaded” / “Windows protected your PC” — normal for new apps. Click Keep → More info → Run anyway. The exe is open-source, embeds the app (no downloader), and has version info (VoiceBox AI 3.3). After a few Keeps SmartScreen trusts it.

FAQ

Does it ask “allow changes”?

Yes, once — the exe has a manifest requireAdministrator. Click Yes so it can register global hotkeys and add background startup. That’s the only prompt outside the tour.

Do I need to open anything else after download?

No. No ZIP to extract, no second installer to hunt for. The exe extracts to %LOCALAPPDATA%\VoiceBox and auto-runs. Just answer the tour.

Why does it need internet?

AI (Groq Llama, Wikipedia, neural voices) needs internet to answer. Install itself works offline — all wheels are inside the 79MB. After install, hotkeys work instantly; answers need connection.

How do I allow microphone/screen?

In the tour step 5 click Allow Microphone / Allow Screen Capture — they trigger real Windows prompts. Windows → Settings → Privacy & security → Microphone / Screen capture to change later.
